SMUDebugTool zh-CN - PawnIO 安装与 I/O 初始化说明
==================================================

SMUDebugTool 需要可用的底层 I/O 驱动才能访问处理器与主板寄存器。

如果程序提示“无法初始化 I/O 模块”或“Error initializing IO module”：

1. 将整个 ZIP 完整解压到普通英文路径。
2. 不要直接从压缩包预览窗口运行 SMUDebugTool.exe。
3. 右键发布包内的 PawnIO_setup.exe，选择“以管理员身份运行”并完成安装。
   本安装包未经修改，来自 PawnIO 官方 GitHub Release：

   版本：2.2.0
   SHA-256：1f519a22e47187f70a1379a48ca604981c4fcf694f4e65b734aaa74a9fba3032
   https://github.com/namazso/PawnIO.Setup/releases/tag/2.2.0

4. 安装完成后重新启动 Windows。
5. 双击 RUN_SMUDEBUGTOOL.cmd；也可以右键 SMUDebugTool.exe，选择“以管理员身份运行”。
6. 如果仍然失败，检查 Windows 安全中心或第三方安全软件是否拦截驱动、DLL 或程序。

注意：

- 发布包内附带未经修改且经过 SHA-256 校验的 PawnIO 官方安装程序。
- PawnIO 官方网站：https://pawnio.eu/
- PawnIO 源码：https://github.com/namazso/PawnIO
- PawnIO 许可证见 PawnIO.LICENSE.txt。
- 对应源码已附在 PawnIO_source_2.2.0.zip。
- PawnIO 2.2.0 使用的 PawnPP 子模块源码已附在 PawnPP_source_e64e4c3.zip。
- 发布包中的 InpOut/WinIo 文件来自原作者 v1.41 Release，用于保持上游兼容性。
- 移动程序目录后，如曾启用“启动时应用已保存的配置文件”，请取消并重新勾选该选项，以更新计划任务中的程序路径。
- 本工具能够修改硬件底层参数，错误设置可能导致系统不稳定、数据丢失或硬件损坏。
