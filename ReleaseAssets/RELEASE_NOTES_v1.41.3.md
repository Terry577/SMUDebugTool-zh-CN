# SMUDebugTool zh-CN v1.41.3

本版本继续基于原作者 SMUDebugTool v1.41，改进 FMax 写入失败时的诊断信息。

主要更新：

- FMax 写入不再把所有失败统一显示为“硬件拒绝”。
- 运行日志会保留 SMU 原始状态码，并提供对应中文说明。
- 可区分前置条件不满足、SMU 忙碌、邮箱超时、PCI 读写失败和命令不受支持。
- 启动时应用配置文件中的 FMax 失败时同样显示具体状态。

安装：

1. 完整解压 ZIP 到普通英文路径。
2. 首次使用时运行 `PawnIO_setup.exe` 安装底层 I/O 驱动，然后重新启动 Windows。
3. 双击 `RUN_SMUDEBUGTOOL.cmd`；它会检查 .NET Framework 4.8.1 并启动程序。
4. 涉及硬件写入时请使用管理员权限，并确认参数适用于当前硬件。

如果 FMax 写入失败，请在 PBO 页右侧运行日志中查看状态码：

- `0xFD`：前置条件不满足，请检查 BIOS/PBO 设置。
- `0xFC`：SMU 忙碌。
- `0x31` / `0x32`：SMU 邮箱超时。
- `0x33`：PCI 读写失败。
- `0xFE`：固件不支持该命令。

本项目及 PawnIO 的许可证、对应源码和第三方说明均已包含在发布包内。
